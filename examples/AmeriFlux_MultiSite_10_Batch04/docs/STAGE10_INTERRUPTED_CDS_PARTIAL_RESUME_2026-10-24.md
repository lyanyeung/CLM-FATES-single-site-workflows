2. If `.download.partial` exists without a receipt, test actual ZIP/NetCDF container integrity, exact hourly UTC coverage, source grid lat/lon, temperature/dewpoint/pressure units and physics using the existing `classify()` + `grid_read()` checks.
3. If a complete partial is valid, rename it to its official immutable `.nc` or `.zip` name, issue a new SHA/BIF/site-year receipt, and reuse without a CDS request.
